# 974 Perfumes — Commerce Frontend

A responsive React storefront built for a Qatar-based fragrance brand.

The project turns a social/WhatsApp-led sales flow into a more structured commerce experience while keeping WhatsApp as the final ordering channel.

## Features

- searchable product catalogue
- category filtering for men, women, unisex, gift sets, and home fragrance
- best-seller and featured-product sections
- interactive cart with quantity controls
- automatic order summary generation for WhatsApp checkout
- responsive desktop and mobile layouts
- video-led hero and branded product presentation

## Tech stack

- **React**
- **Vite**
- JavaScript
- custom responsive CSS

## Why this project is interesting

Rather than building a generic e-commerce template, the frontend is designed around how the business already sells: customers discover products visually, build an order, and complete the conversation through WhatsApp.

That made the project an exercise in both frontend implementation and **designing around a real business workflow**.

## Run locally

~~~bash
npm install
npm run dev
~~~

Production build:

~~~bash
npm run build
~~~

## Status

Frontend commerce prototype. Product information and ordering behavior are implemented in the client; it is not presented as a full payment or inventory backend.
